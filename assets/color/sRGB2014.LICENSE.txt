The registry describes this file as the ICC v2 sRGB profile with the black
point scaled to zero, the media white point at D50, the standard linearized
Bradford D65-to-D50 chromatic adaptation tag, and the header rendering intent
set to perceptual. It was revised in February 2015 so the black point tag
matches the ISO and IEC recommendation.

Why this profile, and not sRGB_v4_ICC_preference.icc:
The v4 preference profile is a different colour encoding, meant to be used
with other v4 profiles. Sharp embeds a profile by converting into it. That
conversion changes saturated colours (pure green 255 becomes about 206, pure
blue 255 becomes about 191). These print pixels are already sRGB. sRGB2014
describes those values, and the same conversion leaves them within one code
value. The old startup URL
https://www.color.org/sRGB_v4_ICC_preference.icc now redirects to an HTML page
and must not be downloaded as the profile.
